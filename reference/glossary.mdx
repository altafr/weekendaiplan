| Term | Meaning |
|---|---|
| **ACV** | Average contract value (per year) for B2B deals |
| **CAC** | Customer acquisition cost: acquisition spend ÷ new paying customers |
| **Founder-touch revenue** | Revenue where the founder personally delivers, sells or is the named draw |
| **Guild / Operator Guild** | The paid $79/month community, run under The AI Edge |
| **Hub** | weekendai.com, the front door that routes visitors to each brand |
| **LTV** | Lifetime value: gross profit from one customer over their expected lifetime (2 years for Guild) |
| **MRR** | Monthly recurring revenue |
| **NRR** | Net revenue retention: this year's revenue from last year's customers ÷ last year's revenue from them |
| **Problem-first** | The Define → Map → Build → Measure → Ship method |
| **Recurring + contracted** | Guild, B2B contracts, retainers, licensing and annual sponsorships |
| **Super-community** | The shared community across all four brands |
| **Transformation Wall** | Public gallery of verified before/after graduate workflows |
