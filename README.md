# WeekendAI Labs: Business Plan wiki (Mintlify)

Internal operating plan for WeekendAI Labs, built with [Mintlify](https://www.mintlify.com/docs).

## Preview locally
```bash
npm i -g mint
mint dev          # http://localhost:3000
mint broken-links
```

## Publish and invite collaborators
1. Push this folder to a new GitHub repository (private is fine).
2. At dashboard.mintlify.com, create a project and connect the repository. Every push to `main` then deploys.
3. In **Settings → Members**, invite collaborators. They can edit in the Mintlify web editor or through pull requests.
4. Optional: add authentication (Settings → Authentication) so only invited people can read the site.

See `reference/contributing.mdx` for the editing rules.
